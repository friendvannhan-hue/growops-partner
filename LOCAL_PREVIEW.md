## Chạy lại

Yêu cầu Node/npm và Python 3. Không cần cài dependencies.

```sh
npm run dev
```

Mở http://localhost:4173/#problems. Dừng server bằng Ctrl+C.

Chỉnh nội dung trong `index.html`; các stylesheet và module được giữ tên gốc để tiếp tục thiết kế.
